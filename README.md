# 唐诡宇宙 · 大唐诡案档案馆

为杨旭文、杨志刚共同主演的《唐朝诡事录》系列制作的非官方资料站。案卷按单元首次出现的顺序排列，案件之间可通过人物和分集索引互相跳转。

## 打开网站

双击 `dist/index.html` 可离线浏览，片方和分集来源链接需要联网。无需安装依赖。用任意静态文件服务器指向 `dist/` 也可运行。收藏仅保存在当前浏览器。

## 内容验收与模型分工

- 参考江湖志的案卷与人物交叉索引，以及寻龙册的分卷检索、谜底折叠和本机收藏。
- OpenCode 的 MiniMax M3.1 Flash Free 起草基础样式、首卷案卷及西行和奇谭的分集提纲。GLM 5.3 Flash Free 起草长安卷的分案边界和任职节点，Codex 对照分集与出品方发布资料修订案名、结局和错误字段。LongCat 2.5 Free 实现检索、来客索引和分集归并的基础逻辑。
- Codex 负责调度、核对收录范围与分集、筛选剧照、集成网站和验收。七牛云初次调用返回 401，按用户确认，后续协作使用 OpenCode 免费模型。
- 运行 `node checks/audit.cjs` 检查案名、篇幅、分集覆盖、引文地址、人物与官职引用、剧照和检索逻辑。对照实际分集校验与程序检查是两项独立工作。

长安卷单元顺序采用长信传媒公布的八案，奇谭的两案采用北京市广电局发布资料。各案、官职条目及人物图在站内附有相应出处。

## 第二版 · 分页、线索配图与外传

首页是导览。案卷、人物、官职、外传和来源各有独立网址片段，原有案卷直达地址与本机收藏可继续使用。

每宗主档案件采用一张对应关键物证或地点的原创线索插图。插图附剧情依据。能确认具体场面的原剧画面另外保留在案卷内，注明集数、场景及来源。人物采用完整比例的《长安》角色海报，薛环换成同套造型图。OpenCode 的 MiniMax M3.1 Flash Free 起草 26 张插图的 SVG 线稿，Codex 检查图形元素，核对插图主题和原剧画面，完成整合与验收。

外传页单列《大唐来的苏无名》《唐诡奇谭之长安县尉》《唐诡奇谭之九重楼》的主案、人物和来源，并链接到对应的主档案件。官职页以《唐六典》卷十四、十八、二十五、三十为官品依据，标明历史类比、州县等第未定、剧中虚衔和临时差遣。来源页按片方与平台、分集与媒体、唐代官制原文分组。

## 第三版 · 原剧封面与 Opus 前端改版

2026 年 11 月 11 日，按用户反馈将 26 宗案卷的封面换为对应单元内的原剧画面，并附图意、集数与来源。人物卡、排版与单元人物切换控件的视觉方案由七牛云海外 Modelink 入口的 Claude Opus 5.5 通过 OpenCode 实际生成，Codex 负责剧照核对、功能整合和验收。方案记录见 content/frontend-design.json，样式见 dist/opus-design.css。

人物海报在卡片上方完整展示，正文在下方。单元人物可在按拼音与按案卷两种视图间切换，按案卷视图按作品与播出单元顺序排列，可跳转案卷，也可从人物名字继续检索。
